RivalLens D2C — Application Flow

The product flow is designed around fast activation, recurring competitive monitoring, and progressively deeper analysis. The user should reach a useful website-based comparison before being asked to configure every optional integration.

Activation target: first reportCore loop: detect → compare → testSecondary loop: explore evidence

1. First-Run Onboarding

Sign up→Enter brand URL→Confirm extracted brand→Add 3–5 rivals→Start analysis→First report

Step details

StepUser actionSystem actionUX rule
1Create accountCreate organization/memberDo not ask company-size/persona questions yet.

5Start analysisQueue website analysis immediatelyOptional social/ad connection can happen after activation.

The Overview is not a traditional KPI dashboard. It is the decision layer. Raw collection volume, crawl counts, and connector metrics belong in Settings/Evidence unless they affect trust.

3. Rival Exploration Flow

Rivals→Select brand→Summary→Choose lens→Inspect evidence

Summary

Top active signals, latest material changes, strongest/weakest observed areas.

Storefront

Products, pricing, offers, bundles, shipping, subscriptions, positioning.

Ads

Creative concepts, offers, landing pages, repeated/long-running observed ads.

Instagram / X

Content themes, formats, outliers, posting cadence, audience response.

Timeline

Material changes across sources in chronological order.

Evidence

Source-specific proof chain, snapshots, and extraction confidence.

6. Degraded & Edge Flows

Instagram unavailable

Continue with website/X/ads. Show coverage gap; never block report generation.

Meta ad connector unavailable

Offer manual Ad Library import or hide ad claims until data exists.

Site blocks crawler

Surface source failure and let user retry/add a specific public URL.

No meaningful differences

Say “No material changes detected” and surface the most recent verified baseline.

Low-confidence extraction

Exclude from executive summary; display in evidence as “Needs review.”

Long-running analysis

Return user to usable current report and update asynchronously when new data lands.

7. Navigation Rules

  • Global nav contains only Overview, Rivals, Compare, Opportunities, Evidence, Settings.
  • Lens tabs appear inside Rival/Compare context and preserve selection while the user explores.
  • Evidence opens in a Sheet/Drawer whenever possible; deep source history can have a full page.
  • Breadcrumbs appear only on nested competitor/evidence pages, not on top-level screens.
  • Command search lets power users jump directly to a competitor, source, signal, or report.
